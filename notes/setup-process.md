# Home Network Lab Setup Process

## Initial Setup

### Router
- Device: Hiveton H5000M
- Firmware: ImmortalWrt 24.10

### Installation and Configuration Steps

1. Installed and configured ImmortalWrt
2. Configured basic network interfaces
3. Verified LAN connectivity
4. Configured internet connection through cellular modem
5. Installed additional network services

## Services Added

### AdGuard Home
Purpose:
- Network-wide DNS filtering
- Improved visibility into DNS requests
- Reduced unwanted advertisements

### Monitoring
Purpose:
- Collect cellular modem information
- Monitor signal performance
- Track network conditions

## Lessons Learned

- Router configuration requires careful testing
- Logs are important for troubleshooting
- Breaking and rebuilding the setup improves understanding
