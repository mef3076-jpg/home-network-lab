# Lab Rebuild Process

## Starting Point

The network lab was reset to a clean factory state to rebuild and document the configuration process.

## Hardware

Router:
- Hiveton H5000M

Cellular Modem:
- RM551

## Rebuild Goals

- Reconfigure router from a clean state
- Document each configuration change
- Improve understanding of network services
- Create repeatable setup steps

## Modem Configuration

The cellular modem firmware was updated to enable additional management and troubleshooting capabilities.

Tasks performed:
- Verified modem communication
- Accessed modem diagnostic interfaces
- Tested connectivity between router and modem

Skills Practiced:
- Embedded device management
- Linux command line
- Hardware troubleshooting
- Network connectivity testing
